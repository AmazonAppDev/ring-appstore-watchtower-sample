# Support

This is an open-source **sample app**, maintained on a best-effort basis.

## Getting help

- **Setup and usage** — start with the [README](./README.md). It has a full deploy walkthrough and a
  Troubleshooting section.
- **Questions and bugs** — open an issue using the appropriate template:
  - [Bug report](./.github/ISSUE_TEMPLATE/bug_report.md)
  - [Feature request](./.github/ISSUE_TEMPLATE/feature_request.md)
- **Contributing** — see [CONTRIBUTING.md](./CONTRIBUTING.md).
- **Security issues** — see [SECURITY.md](./SECURITY.md); do not file these as public issues.
- **Privacy** — see [PRIVACY.md](./PRIVACY.md), a privacy policy template that describes what the
  sample stores. Apps built on this sample need their own policy and support contact.

## Ring platform

For questions about the Ring Appstore (Amazon Vision API) itself — credentials, portal configuration,
or API behavior — refer to the
[Ring App Design Guide](https://developer.amazon.com/docs/ring/ux-design-guide.html), the
[Ring API Reference](https://developer.amazon.com/docs/ring/api-documentation.html), and
[developer.ring.com](https://developer.ring.com/).
